# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Use GitHub's private vulnerability
reporting instead: go to the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the version affected. You will get a response as soon
as the maintainer can; please allow some days.

## Scope

PullLamp runs entirely on-device, uses no network and requests no permissions. Realistic concerns are
things like crashes from crafted input, unbounded resource use, or supply-chain issues in the build.

## Supported versions

Only the latest release receives fixes.
